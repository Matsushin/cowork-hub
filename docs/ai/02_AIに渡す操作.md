# AI に渡す操作（許可リスト）

AI の道具は、API の仕様書（`backend/swagger/v1/openapi.yaml`）から**許可リストにある操作だけ**を自動で作る。
仕様書には管理 API や予約の作成・取り消しも入っているので、全部をそのまま渡さない。
許可リストのコードは `frontend/src/lib/ai/allowlist.ts`（共通の土台で作る）。

## 決め方

1. **読み取り（GET）だけ**。予約の作成・取り消し・会員情報の変更など、書き込む操作は渡さない（確定は人のボタンで既存の処理を通す）
2. **個人情報を返す操作は渡さない**。必要な情報だけを返す操作を選ぶ
3. **会員本人のトークンで呼ぶ**。管理 API（`/api/admin/*`）は、会員向けの機能では渡さない（分析アシスタントは別の許可リストにする）
4. **仕様書の説明は人間向け**なので、AI 向けの説明（いつ使うか・注意点）を許可リストの側で足す

## 予約アシスタント（会員向け）

| 操作 | 渡す | 理由 |
|---|---|---|
| `GET /api/locations`（拠点の検索） | ○ | 場所の条件（拠点名・住所・都道府県）から拠点を探す |
| `GET /api/locations/{id}`（拠点の詳細） | ○ | スペース（会議室の定員・料金）と営業時間を知る |
| `GET /api/locations/{location_id}/spaces/availability`（空き状況） | ○ | 予約済みの時間帯を知る。他人の予約は「誰のものか」なしで返る（`mine` だけ） |
| `GET /api/plans`（料金プラン） | ○ | プランごとの会議室の月の上限を説明する |
| `GET /api/locations/{location_id}/spaces`（スペース一覧） | × | 拠点の詳細で足りる |
| `GET /api/me`（ログイン中の会員） | × | メールアドレスを含む。今の範囲では会員の情報は要らない |
| `GET /api/reservations`（自分の予約一覧） | × | 今の範囲（新しい予約の候補を出す）では要らない。月の上限の残りを出すときに再検討 |
| `POST /api/reservations`（予約する） | × | **書き込み**。人が「この内容で予約」を押したときに、画面から既存の処理で呼ぶ |
| `PATCH /api/reservations/{id}/cancel` など書き込み全般 | × | 書き込み |
| `/api/admin/*` | × | 管理者向け。会員向けの機能では渡さない |
| `/api/session`・`/api/signup` | × | 認証 |

## 見直すとき

- 操作を足すときは、この表に理由を書いてから `allowlist.ts` に足す（PR のレビューで、この表と許可リストが合っているかを見る）
- 許可リストに書き込みの操作（GET 以外）を足すと、テストが失敗する

## 分析アシスタント（管理者向け）

管理者のトークンで呼ぶ。渡すのは**集計した数字だけを返す操作**に限り、会員個人の情報を返す操作は渡さない。

| 操作 | 渡す | 理由 |
|---|---|---|
| `GET /api/admin/stats/usage`（利用状況の集計） | ○ | 予約・ドロップインの件数・時間・金額と稼働率を、拠点・スペース・月・曜日・時間帯でまとめる。数え方は Rails で決まる |
| `GET /api/admin/stats/members`（会員数の集計） | ○ | プランごとの人数・新しい会員・利用した会員の数。人数だけで、個人の情報は返さない |
| `GET /api/admin/sales`（月次売上） | ○ | 月額プランの料金を含めた月の売上の合計。管理画面の「売上」と同じ数字 |
| `GET /api/locations`（拠点の検索） | ○ | 拠点名から拠点の ID を知る（絞り込みに使う） |
| `GET /api/admin/users`・`/users/{id}` | × | 名前・メールアドレスなど個人の情報を含む |
| `GET /api/admin/reservations` | × | 予約ごとに会員の情報を含む。件数などは集計の API で足りる |
| `GET /api/admin/locations/{id}/checkin_code` | × | 受付の QR コード。分析と関係なく、漏れると入館に使える |
| 書き込み全般（会員のプランの変更・スペースの登録など） | × | 書き込み |

## FAQ ボット（会員向け）

会員本人のトークンで呼ぶ。ご利用ルールの検索（`search_rules`）は Rails を呼ばない道具で、許可リストの外（`lib/ai/faq/assistant.ts`）にある。

| 操作 | 渡す | 理由 |
|---|---|---|
| `GET /api/locations`（拠点の検索） | ○ | 拠点名から拠点の ID を知る |
| `GET /api/locations/{id}`（拠点の詳細） | ○ | 営業時間・ドロップインの料金・スペースの料金を答える（文書には書かない値） |
| `GET /api/plans`（料金プラン） | ○ | 月額料金・会議室の月の予約上限を答える |
| `GET /api/locations/{location_id}/spaces/availability`（空き状況） | × | 空きを探すのは予約アシスタントの役目 |
| `GET /api/me`・`/api/reservations`・`/api/billing` | × | 会員ごとの情報。今の範囲（ルールの質問）では要らない |
| 書き込み全般 | × | 書き込み。操作は手順を案内する |
