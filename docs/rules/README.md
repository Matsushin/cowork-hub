# ご利用ルール（FAQ ボットの元の文書）

会員向けのご利用ルール。画面の「ご利用ルール」（`/rules`）に表示し、FAQ ボット（`docs/ai/`）が検索して答えの根拠にする。

## 書き方の約束

- ファイルは `NN_名前.md`。最初の行が `# タイトル`、項目は `## 見出し {#英数字のID}`（ID は画面のリンクと引用に使うので、変えない）
- 1つの項目（`##`）が検索の1単位。1項目には1つの話題だけを、短く書く
- **変わる値（営業時間・料金・プランの上限）は書かない**。拠点やプランの画面（API）が正しい値を持っているので、「拠点の詳細で確認できます」のように書く（FAQ ボットは API から値を調べる）
- コードの動きと食い違わないように書く。ルールを変えたら、このファイルも同じ PR で直す
- 書き換えたら `cd frontend && npm run gen:rules` で検索用のデータ（`src/lib/ai/faq/generated-rules.ts`）を作り直す（CI で最新かを確かめる）
