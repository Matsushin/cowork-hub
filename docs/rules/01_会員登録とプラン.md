# 会員登録とプラン

## 会員登録 {#signup}

名前・メールアドレス・パスワードを入力して登録します。登録すると、すぐにドロップインプラン（月額0円）で使い始められます。登録やログインにお金はかかりません。

## プランの種類 {#plans}

プランは、ドロップイン・月額ライト・月額フルの3つです。
- ドロップイン：月額0円。拠点を使った時間の分だけ料金がかかります。
- 月額ライト・月額フル：月額料金で、全国の拠点のドロップイン利用が使い放題（追加の料金なし）です。
- プランごとに、会議室を予約できる時間の月の上限が決まっています（月額フルは上限なし）。

月額料金と予約の上限の時間は、料金プランの一覧で確認できます。

## プランの変更 {#change-plan}

プランの変更は、会員の画面からはできません。スタッフにお申し付けください。変更した日から新しいプランになります。

## 会員情報の変更 {#profile}

名前・メールアドレス・パスワードは、「会員情報」の画面からいつでも変えられます。今のプランも同じ画面で確認できます。
